# DRIVE GUARD — 居眠り見守り（試作版）

スマートフォンの前面カメラを使い、顔と目の状態から閉眼が続いたことを検知して警報を出す**検証用Webアプリ**です。

## 公開手順（GitHub Pages）
1. GitHubで `drive-guard` リポジトリを作成します。
2. このフォルダ内の `index.html` と `README.md` をリポジトリの最上位にアップロードします。
3. リポジトリの **Settings → Pages → Build and deployment** を開きます。
4. **Source: Deploy from a branch**、**Branch: main**、**Folder: /(root)** を選択して Save します。
5. 表示される `https://<ユーザー名>.github.io/drive-guard/` にアクセスします。

## 利用方法
- HTTPSで公開したページを開き、カメラアクセスを許可します。
- カメラを顔の正面付近に固定し、**停車中**に動作確認します。
- 警報の音量を確認し、通知への反応や誤検知の有無を試験します。

## 必須の注意点
- **これは試作版であり、運転中の居眠り防止・事故防止を保証しません。** 運転中にスマホを操作しないでください。
- 警報が出た場合は安全な場所で停止し、運転の継続可否を確認してください。音だけで眠気を解消することはできません。
- ブラウザーやOSの制約によって、バックグラウンド時のカメラ処理・警報は停止する場合があります。画面を表示した状態で使用してください。
- AIモデルと実行ライブラリは外部CDNから取得します。初回起動時にインターネットが必要で、取得先との通信が発生します。
- GitHub Pagesは、非公開リポジトリであってもサイトが一般公開される場合があります。機密情報や運転手の個人情報をページに含めないでください。
- 医療機器や認証済み安全装置ではありません。実際の運転への適用前に現場で検証してください。
